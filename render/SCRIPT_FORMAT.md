# リール台本JSONの書き方（render_reel.py 用）

動画は 1080x1920・30fps。`python3 render_reel.py 台本.json 出力フォルダ` で mp4 と qa.json（自動チェック結果）、frames/（確認用静止画）ができる。

## 全体
```json
{
  "id": "reel01",
  "series": "ひとり事務の時短 #01",      // 左上のバッジ（短く）
  "scenes": [ ... ],                      // 上から順に再生
  "caption": "投稿文（改行可）",
  "hashtags": ["#Excel", "#スプレッドシート"]   // 5個まで
}
```

## 文字の共通ルール
- `*ここ*` で囲んだ部分は黄色で強調。
- **改行は必ず `\n` で自分で入れる。** 意味の切れ目で改行し、1行は全角10〜12字以内。「る？」「す」だけが次の行に残る改行はしない。
- 1場面の文字数は「秒数×7字（7.5字/秒を超えると警告）」以内（読める速さの目安）。超えるとqa.jsonに警告が出る。
- 数式・関数名は半角。

## テンポ（2026-11-05 社長の方針）
- **短く・速く。** 全体は12〜20秒を目安にする（漢字は15〜20秒）。冒頭は2秒前後で「何の得があるか／何問出るか」を言い切る。
- sheet は1場面5秒前後（type_at 0.3・type_len 1.0〜1.4）、2場面まで。compare・points は省くか2.5秒以内。cta は2秒。
- 1本に詰め込む情報は少なく、見せ場（数式→結果）を早く出す。

## 読み上げ（ナレーション）
- 場面に `"say": "読み上げる文"` を書くと、その場面の始まり（`"say_at"` 秒後、既定0.05）に合成音声で読む。クイズの `"say_answer"` は答えが出た瞬間に読む。
- 文は短く（1場面で1文・場面の長さに収まる量）。英字の関数名は読み間違えるのでカタカナで書く（例：SUMIFS→「サムイフス」、XLOOKUP→「エックスルックアップ」）。
- 全体の読む速さは `"voice_speed"`（既定1.15。速いテンポなら1.3〜1.4）。声を入れたくない台本は `"voice": false`。
- 声がある場面は、画面の文字が少し多くても警告しない（目安11字/秒まで）。
- 声を使うと、投稿文の最後に「※ナレーションは合成音声です。」が自動で入る（Instagramの合成音声の開示ルールのため）。

## quiz（クイズ1問。2.4〜2.8秒）
大きな問題カード → 減っていく時間バー → `reveal_at` 秒で答えがはじける。5問ほど続けて1本にする。
```json
{"type": "quiz", "dur": 2.6, "q": "蝸牛", "a": "かたつむり", "no": 1, "of": 5, "reveal_at": 1.4,
 "say_answer": "かたつむり", "note": "出典：デジタル大辞泉"}
```

## 場面の種類

### hook（冒頭。2.5〜3.5秒）
背景に、最初の sheet 場面の完成画面が薄く表示される（文字だけの動画にしないため）。
```json
{"type": "hook", "dur": 3.0, "text": "取引先リストの重複\n*まだ手で消してる？*", "sub": "関数1つで一瞬です"}
```

### sheet（本編。スプレッドシートの操作を見せる。6〜9秒）
```json
{"type": "sheet", "dur": 8.0,
 "title": "空いている列に入力",                 // 上の見出し（短く。2行まで）
 "rows": [["取引先","金額"],["A商事","1,200"]],  // 1行目が見出し行。最大4列・最大9行程度
 "widths": [2, 1],                               // 列幅の比率（省略可）
 "target": "C2",                                 // 数式を入れるセル
 "formula": "=UNIQUE(A2:A8)",                    // 数式バーにタイピングされる
 "type_at": 0.9, "type_len": 1.6,                // タイピング開始秒・所要秒（省略可）
 "highlight": "A2:A8",                           // 参照範囲を黄色で表示（省略可）
 "result": "A商事",                              // Enter後に target に出る値
 "spill": [["C3","B工業"],["C4","C物産"]],       // 他のセルにも結果が出る場合（スピル・下にコピー）
 "note": "*重複を除いた一覧*が\n自動で並ぶ"       // 下の補足（2行まで）
}
```
- `keys` を使うとキー操作の紹介になる: `"keys": ["Ctrl","Shift","L"]`（formulaはEnter後に数式バーに表示）。
- 表の中の値は短く（1セル全角6字程度まで）。

### compare（Before/After。3.5〜4.5秒）
```json
{"type": "compare", "dur": 4.0, "title": "作業時間", "before": "目で探して削除\n10分", "after": "関数1つ\n数秒", "before_label": "いつものやり方", "after_label": "この方法"}
```

### points（要点。3つまで。4〜6秒）
```json
{"type": "points", "dur": 5.0, "title": "使えるのは", "items": ["Excel 2021以降", "Microsoft 365", "Googleスプレッドシート"]}
```

### cta（締め。2.5〜3.5秒）
```json
{"type": "cta", "dur": 3.0, "text": "*保存*して\nあとで試そう", "sub": "ひとり事務の時短ワザを\n毎週投稿中"}
```

## 音
- 効果音に加えて、自作のBGM（標準はシティポップ風・約110BPM）が自動で入る。曲はプログラムで合成するので著作権の問題はない。台本の id で調・コード進行・テンポが変わる。
- 曲の雰囲気を変えたい台本だけ、全体に `"bgm_style"` を書く：`"city"`（標準）／`"pop"`（明るいポップ）／`"uke"`（ウクレレ風）／`"chip"`（電子音）／`"lofi"`（落ち着いた曲）／`"wa"`（和風：琴・尺八。漢字アカウントの標準）。
- BGMを入れたくない台本だけ、全体に `"bgm": false` を書く。

## 推奨構成（12〜20秒）
hook → sheet（1〜2場面）→ compare または points → cta。sheet場面の合計が全体の半分以上になるように。

## 投稿情報（必須）
台本ごとに `post` を必ず書く。動画を作ると同じフォルダに「投稿情報.md」（表紙の文字・投稿文・ハッシュタグ・代替テキスト・音源・投稿時間・投稿後の作業）ができる。投稿文の最後には共通の締め文（保存の呼びかけ・コメントの呼びかけ・@aiaiai4772）が自動で付く。
```json
"post": {
  "cover_title": "取引先の重複を\n関数1つで整理",          // 表紙に入れる文字（2行まで）
  "alt_text": "どんな操作の動画かを1〜2文で",              // 代替テキスト（目の不自由な人向けの説明）
  "post_time": "平日 12時台 または 20〜21時台（目安）",
  "notes": ["税の話題なので投稿直前に出典ページを再確認"]   // 任意
}
```
- ハッシュタグは5個まで（Instagramの上限）。
- 投稿文に数式をコピーできる形で書く。誇大表現・節税をあおる表現は書かない。
- 投稿だけ作り直すとき：`python3 render_reel.py 台本.json 出力フォルダ --post-only`
